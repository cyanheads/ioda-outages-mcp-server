# 0.3.0 — 2026-10-28

## Added

- **`ioda-outages-guide` agent skill** (`skills/ioda-outages-guide/SKILL.md`) is served as the resource `skill://ioda-outages-guide/SKILL.md` under the template `skill://{+path}` through `createApp({ skills })` ([mcp-ts-core#789](https://github.com/cyanheads/mcp-ts-core/issues/789), mcp-ts-core 0.13.18); `initialize` advertises `io.modelcontextprotocol/skills`, and the skill also ships in `skills/` in the npm package, Docker image, and `.mcpb`. It covers resolving countries, regions, and networks to IODA codes, `asn` vs `geoasn`, publication lag, signal resolution, and reading alerts, rankings, and signals without over-claiming. `tools/list` is unchanged.
- **Agent Plugins root `plugin.json` and `mcp.json`** beside the `.claude-plugin/` and `.codex-plugin/` manifests ([mcp-ts-core#426](https://github.com/cyanheads/mcp-ts-core/issues/426), mcp-ts-core 0.13.18).

## Changed

- **`.mcpb` bundle no longer ships repo-local root files** (`CLAUDE.md`, `AGENTS.md`, `changelog/`, `.claude-plugin/`, `.codex-plugin/`, `.dockerignore`, `.gitattributes`, `devcheck.config.json`) **or the framework's build-only package files** (`templates/`, `changelog/`, `scripts/`, `config/`, its `CLAUDE.md`/`AGENTS.md`), which the 0.2.1 bundle carried: anchored `.mcpbignore` ([mcp-ts-core#508](https://github.com/cyanheads/mcp-ts-core/issues/508), mcp-ts-core 0.13.18) and `clean-mcpb` build-only stripping ([mcp-ts-core#791](https://github.com/cyanheads/mcp-ts-core/issues/791), mcp-ts-core 0.13.18).
- **Development:** `bunfig.toml` `minimumReleaseAge` drops from 3 days to 1 day (mcp-ts-core 0.13.17 template); framework skills and packaging scripts are synced, including a local fix so the bundle cleaner and packaging lint keep the MCP SDK's runtime `dist/ext/skills/` modules ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), still open upstream).

## Fixed

- **The Streamable HTTP transport no longer retains memory for every request when run under Bun, as the Docker image does.** 0.2.1 was built on mcp-ts-core 0.13.16, which held each request's signal past its response; mcp-ts-core 0.13.17 releases it when the response ends ([mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).
