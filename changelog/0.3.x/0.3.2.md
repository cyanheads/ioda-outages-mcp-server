# 0.3.2 — 2026-11-21

## Added

- **`ioda_find_outages`** accepts `time_asc` (oldest first, default), `time_desc`, and `score_desc`. IODA sorts before paging and the tool echoes `applied.order`. Use `source` with `score_desc` to compare scores on one scale. ([#31](https://github.com/cyanheads/ioda-outages-mcp-server/issues/31))

## Changed

- **`ioda-outages-guide` 1.2** documents event ordering, exclusion notices, and status publication allowances.
- **Development and packaging** now require Bun 1.4.4 or later. Updated framework skills and tooling, including MCPB cleanup for dependency agent docs.

## Fixed

- **`ignoreMethods`** names exclusions that match no known IODA detection method on events, alerts, and rankings. Valid normalized exclusions still go to IODA and appear in `applied.ignoreMethods`. ([#29](https://github.com/cyanheads/ioda-outages-mcp-server/issues/29))
- **`ioda_get_status`** allows 10,800 seconds for Merit and 1,800 for BGP and active probing. `applied.signals.publicationAllowances` reports all three values, and the legacy scalar stays at 1,800. ([#30](https://github.com/cyanheads/ioda-outages-mcp-server/issues/30))
- **Transport diagnostics** log allowlisted codes and fixed categories from failed fetches and response streams, including aggregate causes. The MCP error contract stays the same. ([#27](https://github.com/cyanheads/ioda-outages-mcp-server/issues/27))
- **Clamp telemetry** registers its counter at module load using the framework's deferred instrument support.
