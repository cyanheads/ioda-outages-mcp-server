# 0.2.1 — 2026-10-24

## Added

- **`ignoreMethods`** on events, alerts, and rankings excludes `source.method`, `source.*`, or `*.method` upstream before scoring; keep exclusions fixed across pages and drill-downs. ([#15](https://github.com/cyanheads/ioda-outages-mcp-server/issues/15))
- **Lexical input patterns** advertise entity/source vocabularies, identifier grammar, and trimmed query length across all six tools; schema failures return `invalid_arguments` with corrective guidance while accepted normalization remains available. ([#14](https://github.com/cyanheads/ioda-outages-mcp-server/issues/14))

## Changed

- **Hosted connection metadata** documents the public Streamable HTTP endpoint in the README and MCP Registry entry.
- **Project tooling** synchronizes framework guidance and audit classification of direct versus transitive vulnerable package copies.

## Fixed

- **Window guidance** distinguishes inclusive detection selection from exclusive returned signal bucket bounds and warns that adjacent windows can duplicate boundary detections. ([#11](https://github.com/cyanheads/ioda-outages-mcp-server/issues/11))
- **Related-scope outage responses** disclose unverified membership coverage even on empty or exhausted pages and provide resolver plus per-entity recovery calls with the original filters. ([#13](https://github.com/cyanheads/ioda-outages-mcp-server/issues/13))
- **Coarse signal guidance** discloses that aggregates need not equal an unweighted mean of finer returned buckets and can conceal missing observations; status retains unknown coverage. ([#16](https://github.com/cyanheads/ioda-outages-mcp-server/issues/16))
