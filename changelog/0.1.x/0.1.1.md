# 0.1.1 — 2026-10-21

## Added

- **`ioda_search_entities`** resolves country, region, and autonomous-system identifiers with zero-based pagination.
- **`ioda_get_status`** reports recent detection evidence separately from measurement coverage, preserving partial component failures and completed-bucket freshness.
- **`ioda_find_outages`, `ioda_get_alerts`, and `ioda_get_signals`** retrieve source events, transitions, and BGP, active-probing, and Merit telescope observations with original scores, nulls, timing, and attribution.
- **Bounded, lossless responses** preserve the same data on both MCP response surfaces; oversized requests receive concrete recovery guidance instead of truncated evidence.
- **Keyless IODA access** runs over stdio or stateless Streamable HTTP with shared request pacing, cancellation, and invocation deadlines.
- **Installation and investigation documentation** covers client configuration, tool contracts, uncertainty, and private vulnerability reporting.
